# 隐藏提示圆点语义浮层设计

## 背景与目标

关系图中的线段自由端圆点表示画面之外仍有节点，但当前圆点只提供视觉暗示。用户点击圆点后，需要立即知道：

1. 圆点表示哪一种隐藏关系；
2. 关系从哪张卡开始；
3. 后面具体隐藏了哪些节点；
4. 哪些节点可继续打开。

本次采用方案 A：圆点旁的轻量浮层。浮层不改变图布局，不展开或移动现有卡片。

## 交互规则

- 单击圆点打开浮层；再次单击同一圆点关闭。
- 单击另一个圆点时，原浮层被新浮层替换。
- 单击浮层和圆点之外的空白区域，或按 `Escape`，关闭浮层。
- 拖动画布或开始双指缩放时关闭浮层，避免浮层与锚点脱节。
- 只有指针按下和抬起之间未超过现有拖动阈值时才算点击。
- 浮层放在根视口上的独立 DOM 层，不参与画布缩放；位置由圆点画布坐标、当前平移量和缩放比例换算，并限制在可见区域内。
- 浮层默认位于圆点右下侧；右侧空间不足时翻到左侧，下侧空间不足时翻到上侧。

## 浮层内容

浮层包含四部分：

1. 关系标题：`连续内容`、`题外分支`、`来源行后续` 或 `上级路径已折叠`。
2. 一句话解释，例如：`1/13 后面还有未显示的数字子级。`
3. 来源标签：显示语义来源节点的标题与编码；若视觉锚点与语义来源不同，以语义来源为准。
4. 隐藏节点列表：按关系图中的稳定顺序显示标题和编码。

真实笔记节点整行可点击，点击后沿用卡片导航逻辑切换焦点并打开对应笔记。幽灵节点置灰，显示 `笔记尚未创建`，不触发导航。列表超过 6 项时，浮层内部滚动，浮层宽度保持紧凑。

## 圆点语义

- `continuation`：隐藏的直接数字子级，标题为 `连续内容`。
- `offTopic`：隐藏的直接字母子级，标题为 `题外分支`。
- `sourceTail`：来源数字同行中被截断的后续节点，标题为 `来源行后续`。
- `fold`：为了保持局部视图简洁而省略的祖先路径，标题为 `上级路径已折叠`；列表按从根到近端父级的顺序显示。

实线或实心视觉用于连续关系，虚线或空心视觉用于题外关系；视觉样式不作为隐藏节点列表的数据来源。

## 数据模型与职责边界

`focus-projection.ts` 在创建 `HiddenHint` 时同时记录：

- `anchorId`：圆点和提示线的视觉锚点；
- `sourceId`：产生隐藏关系的语义来源节点；
- `hiddenIds`：该提示实际代表的隐藏节点编码，顺序已经确定。

这能覆盖根节点继续提示被画在来源行末卡右侧的特殊情况：圆点可锚定 `1/1`，语义来源仍是根节点 `1`，列表仍展示根节点未显示的数字子级。

`hidden-hint-markers.ts` 只负责把语义提示与真实路由端点合并，输出可渲染的 `HiddenHintMarker`。每个标记携带关系标题、解释所需的来源卡、隐藏卡列表、圆点坐标与线型信息。

`renderer.ts` 负责把标记圆点渲染进 SVG，并写入稳定的标记 ID 和无障碍标签，不负责浮层状态。

`main.ts` 负责当前打开标记、浮层创建与关闭、视口坐标换算、空白区与键盘交互，以及复用现有卡片导航。

`gen-real-preview.mjs` 使用同一份标记数据生成可点击预览；预览中的浮��交互与插件保持一致，但节点点击只用于展示选中反馈，不打开 vault 文件。

## 数据生成规则

- 创建 `continuation` 时，`hiddenIds` 取当前语义节点未出现在所有可见泳道中的直接数字子级。
- 创建 `offTopic` 时，`hiddenIds` 取当前语义节点未出现在所有可见泳道中的直接字母子级。
- 创建 `sourceTail` 时，`hiddenIds` 取来源同行在截断点之后的节点；若同位置已经存在语义等价的 `continuation`，继续沿用去重规则。
- 创建 `fold` 时，`hiddenIds` 取来源行首卡的祖先节点，并排除当前已经可见的节点。
- 空列表不生成圆点，避免出现点击后没有内容的提示。

## 错误与边界处理

- 标记的隐藏节点已从索引移除时，刷新会重新投影并移除该项。
- 节点存在但没有文件路径时按幽灵节点处理。
- 多个提示共用坐标时，按提示类型生成独立稳定 ID；当前仅打开一个浮层。
- 浮层打开后刷新、焦点切换或重建索引时立即关闭。
- 缩放比例不影响浮层字号和点击区域；圆点本身随画布缩放。

## 测试策略

1. 投影测试：四种提示都携带正确的 `sourceId` 和 `hiddenIds`，包括根节点视觉锚点与语义来源不同的情况。
2. 标记测试：路由端点、关系文案、来源卡和隐藏卡列表正确合并；折叠和合并主干端点继续保持正确。
3. 渲染测试：SVG 圆点具有按钮语义、稳定 ID、类型和无障碍标签。
4. 交互测试：打开、切换、再次点击关闭、空白关闭、`Escape` 关闭、拖动关闭。
5. 导航测试：真实节点复用卡片导航，幽灵节点不触发打开文件。
6. 回归测试：全部布局、连线、拖动和缩放测试继续通过。
7. 真实预览验收：至少检查 `1/11` 的连续提示、题外提示，以及 `1/11c` 的折叠提示。

## 验收标准

- 每个可见圆点都能说明自身含义并列出实际隐藏节点。
- 列表顺序与关系图一致，标题、编码、幽灵状态准确。
- 真实节点可点击导航，拖动画布不误触。
- 浮层不改变卡片坐标或连线路由，缩放后仍清晰可读。
- 键盘可聚焦圆点，可用 `Enter` 或空格打开，并可用 `Escape` 关闭。

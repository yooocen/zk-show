# 卡片画布指针与缩放交互

## 目标

画布同时支持鼠标、触屏与触控笔操作：单指或鼠标左键平移、双指捏合缩放、`Ctrl + 滚轮` 缩放。既有的卡片点击跳转和双击复位应继续可用。

## 交互规则

- 单个活动指针平移画布；移动超过 3px 后抑制本次卡片点击。
- 两个活动指针进入捏合模式。缩放中心为两指中点，缩放比例由当前距离与起始距离的比值决定。
- `Ctrl + 滚轮` 以鼠标位置为中心缩放；普通滚轮保留给宿主滚动行为。
- 缩放比例限制在 0.5 到 2.5。双击把缩放恢复为 1，并将当前卡片居中。
- 触摸取消、指针离开和视图关闭都清理活动指针与拖动状态。

## 实现边界

抽取不依赖 DOM 的视口变换模块，保存 `panX`、`panY` 与 `scale`，并提供按指定视口焦点缩放的计算。视图层只负责把 Pointer/Wheel 事件转换为状态调用，并把状态应用到画布的 `translate(...) scale(...)` 变换。

## 验证

- 单元测试：平移、以焦点缩放、缩放上下限。
- 单元测试：双指距离变化计算比例。
- 手工验证：鼠标拖动、触屏单指拖动、双指捏合、`Ctrl + 滚轮` 与双击复位。

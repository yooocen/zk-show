# 卡片标题两行截断与统一高度设计

## 背景

当前卡片标题使用单行省略，标题稍长时第一行就被截断；卡片布局尺寸由统一的 `measureCard` 提供，但高度仍为 72px。目标是让标题优先换行，在两行都无法完整展示时才截断，并统一提高卡片高度。

## 目标

- 卡片统一使用 240px 宽、96px 高。
- 标题允许自然换行，最多展示两行。
- 只有第二行仍放不下时才显示省略号。
- 保留编码、分隔线、标题和连接指示器的现有结构与交互。
- 保证布局计算、边缘避让和渲染 DOM 使用同一套卡片尺寸。

## 非目标

- 不按标题长度动态改变单张卡片高度。
- 不修改卡片宽度、关系线语义、卡片点击行为或连接指示器逻辑。
- 不在数据层预先改写或截断标题文本。

## 设计

### 布局尺寸

将 `src/layout/geometry.ts` 中的 `LAYOUT_METRICS.cardHeight` 从 72 调整为 96。`measureCard` 继续返回固定宽高，因此编译器、求解器、路由器和最终渲染器都自动共享 240×96 的卡片矩形。

### 标题呈现

将 `styles.css` 中卡片标题改为多行截断：

- `white-space: normal`，允许普通文本换行；
- 使用 `display: -webkit-box`、`-webkit-box-orient: vertical` 和 `-webkit-line-clamp: 2` 限制为两行；
- 保留 `overflow: hidden` 和省略号语义；
- 增加 `overflow-wrap: anywhere`，覆盖连续英文、数字路径和无空格字符串；
- 标题字号调整为 17px，行高保持约 1.25，以匹配 B 方案的标题层级。

标题仍由 `.zk-show-card-body` 垂直居中，短标题不会被强制拉伸；编码区域继续单行省略。

## 验证

1. 单元测试确认不同标题输入返回相同的 240×96 尺寸。
2. 现有布局回归测试确认卡片不重叠、卡片边界有效、关系线仍保持避让。
3. 运行完整 Vitest 测试和生产构建。
4. 在预览中检查短中文、两行中文、连续英文/数字和超长混合标题，确认第一行放不下时换行，第二行放不下时才截断。

## 风险与处理

`-webkit-line-clamp` 是 Obsidian 桌面 Chromium 环境常用的多行截断能力。若某些环境不支持该属性，`overflow: hidden` 仍能避免内容溢出，但省略号表现可能退化；布局尺寸和交互不受影响。
